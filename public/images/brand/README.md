# Recursos de marca de GaleoTrack

- `galeotrack-logo.png`: original proporcionado por el proyecto, conservado sin modificaciones.
- `galeotrack-logo.webp`: versión para la interfaz, con el margen transparente recortado y un ancho máximo de 960 px. Mantiene los colores y las proporciones del original.
- Los iconos de aplicación de `app/` utilizan el símbolo central del logo sobre el azul `#05275E`.

El logo plateado se presenta sobre una superficie azul profunda. No usar filtros CSS para recolorearlo, estirarlo ni añadir un segundo nombre junto al logotipo.
